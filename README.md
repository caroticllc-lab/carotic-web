# CAROTIC website

This is a responsive, single-page Carotic LLC website starter designed around the supplied Carotic logo and business information.

## Files
- `index.html` — main website
- `styles.css` — design, responsive layout and animations
- `script.js` — scroll reveal animation
- `assets/carotic-logo.jpg` — supplied logo
- `assets/favicon.jpg` — favicon

## Deploy on Vercel
1. Create a free account at Vercel.
2. Create a new project and upload this folder (or connect a GitHub repository).
3. Deploy.
4. Vercel will give you a `vercel.app` address.
5. Later, connect a custom domain such as `caroticllc.com`.
